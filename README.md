# modelviewer

## Deployment

Pull requests from this repository targeting `main` publish a shared preview at
<https://mrfcoelho.github.io/modelviewer/preview/>. The preview updates when a
pull request is opened, reopened, or receives new commits. If multiple pull
requests are open, the most recently deployed one is shown there.

The production site remains at <https://mrfcoelho.github.io/modelviewer/> and
updates when changes are pushed to `main`.
